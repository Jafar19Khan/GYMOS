# GYMOS design system

Premium, high-contrast fitness editorial aesthetic: focused, confident and energetic without clutter.

| Token | Hex | Use |
| --- | --- | --- |
| Obsidian | `#090B0A` | Primary background |
| Graphite | `#171D19` | Surfaces/sections |
| Electric Lime | `#B6F36A` | Primary action/emphasis |
| Emerald | `#39C98A` | Positive/active states |
| Mist | `#E8ECE7` | Primary text |
| Warm Amber | `#E5A94D` | Caution/highlights |

Approximate balance: 65% dark base, 20% graphite, 10% lime/emerald, 5% neutral/amber. Use responsive layouts, visible keyboard focus, readable contrast, comfortable touch targets and reduced-motion support. Use licensed/original gym imagery; do not hotlink unknown sources.
