# GYMOS frontend

The Next.js App Router application lives here. Run repository-level scripts from the root.

- `npm run dev` — local development
- `npm run lint` — ESLint
- `npm run typecheck` — strict TypeScript check
- `npm run test` — Vitest suite

The initial screen is a responsive marketing/design foundation. Dashboard features will be protected by server-enforced authorization as domain milestones are implemented.
